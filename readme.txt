Gives every commenter, user and subscriber without an avatar an image from your own set.

== Description ==

Developed by Liquid Media (https://belikeliquid.com).

* Random avatar from your image set for anyone without one
* Same person always gets the same image
* Add images from the Media Library, remove any image, or restore the 5 starters
* Becomes the site default avatar on activation
* Keep real Gravatars, or skip Gravatar and serve everything from your site

== Installation ==

1. Upload the plugin folder to /wp-content/plugins/
2. Activate it under Plugins
3. Go to Settings > Avatar Randomizer
